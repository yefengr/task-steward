# 统一交付、验收清理与暂停接续生命周期

## 目标与适用范围

交付表示本轮已有可验收的结果，不表示 Pi 已退出，也不表示用户已经验收。正常交付后，Pi 完成本轮验证、记录和必要回报，再明确结算工作、释放其后台名额，保留正在运行的会话等待验收。

本方案承接已确认的生命周期讨论，复用前台纳管与原会话接续、基准分支与安全合并清理能力，不重新建设执行端或 Git 管理器。事项状态只在 [ROADMAP](../../ROADMAP.md) 维护；本方案说明行为、实现边界和验证要求，不代替源码接口真源。

## 会话、工作与名额

- 执行尝试继续承载原电脑、进程所有权、原生会话和实际现场。保留同一进程续做时，以有版本的工作段及事件记录授权、结算和接续，不另启第二份 Pi。
- 保存交付只进入待验收；全部工作收尾后调用结算工具，才释放后台名额。仅等待用户回答的后台工作尚未结算，仍占名额。
- 名额限制后台自动领取，不限制原 Pi 中用户明确授权的前台续做，也不是 Pi 进程总数上限。页面关闭、断网和一段时间没有消息不改变执行方式。
- 工作台请求返修或后台继续仍须取得后台领取资格。原专用进程仍在时复用它；必须换进程时，先确认旧进程退出，再使用原现场和原对话。

## 交付后的两种修改

**实质续做或正式返修**必须取得明确授权，转换任务状态与实施权限，并记录对应的交付版本和原因。原会话不能在平台仍认为工作已封闭时继续隐性实施。工作段版本使旧请求不能污染新一轮；不能凭会话历史恢复权限。

**仅补交付记录**使用独立工具和记录权限，可补充最终报告、已有验证结果和遗留事项。每次生成新版本，保留来源、修订原因和旧版；不重开实施、不重新排队，也不为补记录重复提交代码、发布或部署。代码引用保持原交付的确切版本。用户只能验收最新版本，补记录与验收通过事务和版本校验互斥。

讨论仍由用户明确请求结束，并经平台确认后才整理结论、未决事项、交付和结算。已有结论、当前回合结束或无人回复都不构成结束请求。

## 主动暂停与继续

暂停是用户主动停止当前 Pi，不是交付、取消或验收。确认前必须说明：当前回复或工具可能中止；文件不会回滚；已发出的外部操作可能已经生效。

暂停期间显示处理中。只有执行端可靠确认旧进程停止，才显示已暂停并释放其后台名额。离线、超时或结果未知不得当作成功，不自动重派。普通前台 Pi 通过原会话控制请求停止，启动器不得把任意 PID 当作可杀目标。

继续复用原机器、实际目录／工作树、分支和原生对话。恢复并确认加载后，智能体先读取最新任务、授权和实际进展，核对中断操作的结果；下一步明确且在授权内则继续，有缺口或无法查清的外部操作则提问等待。它不同于仅打开对话、等待用户消息的普通重启／恢复，也不重放原开工指令。

现场或会话缺失、分支不符时停止并说明原因，不回退登记目录、不创建替代工作树或空会话。暂停任务不能从普通重新安排入口绕过原现场接续。

## 验收、合并与清理

代码任务顺序为：

1. 保存交付，完成本轮收尾并结算，保留 Pi。
2. 用户确认具体交付版本，冻结该版本，交给原电脑程序安全合并。
3. 合并成功才算最终验收成功。合并失败仍未验收完成，保留现场，按正式流程修复、验证、重新交付和重新确认。
4. 封闭该任务的实施、返修和记录修订权限，进入清理环境。
5. 确认专用任务 Pi 退出，再安全移除任务工作树和分支，最后完成。

讨论、只读任务没有 Git 合并；人工验收后进入适用的退出清理。启动器专用的任务 Pi 在验收成功后退出。用户自己打开的普通前台 Pi 仅封闭任务权限、解除绑定，不关闭整个会话，仍可承接其他新目标。普通 Pi 仍可能使用其逻辑工作树时，保留既有受阻门禁，不自动关闭它或强删现场。

清理失败只重试退出确认或清理，不重复合并，不重开实施。占用、未提交改动、所有权不符或退出未确认都必须显示具体原因；离线等待原电脑。保留任务、交付、验收、事件和原生会话历史，不删除项目原目录、基准分支或无关用户文件。验收成功是任务终结边界，后续独立工作另行授权并由新任务承接，不自动创建。

## 实现与验证边界

共享接口由 `packages/contract` 维护，直接消费者统一核验；平台负责事务与权限，启动器负责可核验进程事实和确定性 Git 操作，Pi 扩展负责显式授权工具与原生会话控制，工作台展示阶段、处理结果和下一步。

验证需覆盖结算保留进程与两端名额、前台不限额和后台准入、记录修订与验收竞争、续做代数隔离、暂停未知结果与继续现场校验、合并失败再交付、验收后拒绝业务写入、退出确认及清理重试，并包含取消和迟到回报。执行根 `pnpm verify`、`git diff --check`，页面须浏览器验收。真实 Pi／Mac／启动器隔离验证与正式 LaunchAgent、Pi Reach、生产接入分别说明，不用前序证据冒充本功能已验收。

本次实施不包含提交、推送、合并当前任务、发布、部署、宿主安装、修改真实用户配置、跨机器迁移、批量／定时暂停或新执行端。

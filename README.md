# Pi Steward — 任务管家

Pi Steward 是面向个人的跨电脑任务清单与执行协调系统：在自己的清单中安排工作，由项目所在 Mac 上的 Pi 讨论和执行，集中查看交付、接收通知并完成验收。

`pi-steward` 是当前项目目录名与工作名称，正式产品名称尚未确定。

## 当前范围

本项目目前只包含根据已确认讨论整理的方案文档，尚无运行代码、安装程序或线上服务。创建文档不代表已经完成开发、部署、Pi Reach 集成或真实设备验收。

## 阅读重点

控制台部署在私人服务器上，只负责保存任务与协调流程。所有模型活动发生在项目所在的 Mac；进入任务对话时使用 Pi Reach。代码与工作现场保留在执行电脑，中心保存任务说明、交付报告及版本引用。

任务不刻意划分讨论与执行类型，保存待办与安排开始仍是两个动作。需要用户回应时，直接在任务对应的 Pi Reach 会话交流；等待回应的会话继续占用该 Mac 的活跃会话名额。每台 Mac 可单独配置上限，默认 1，worker 确认会话结束和释放后才归还名额。

下一步是补齐技术方案中的回传字段、身份、完整状态转换和收尾恢复协议，再验证从任务派发到对话、交付、通知、验收和续跑的完整流程。

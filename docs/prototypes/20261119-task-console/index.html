建议走查路径

路径操作
验收需要我处理 → 「平台数据表设计」→ 查看 v2 交付与 v1 历史 → 验收 v2
返修同一任务 → 返修 → 填写反馈 → 任务回到待领取，显示「返修，将优先领取」
回答问题需要我处理 → 「会话深链参数设计」→ 在 Pi Reach 中打开（模拟提示）
中断处理需要我处理 → 「设置页字号档位」→ 重新安排或取消任务
记录并安排新建任务 → 只填标题 → 在项目列表的未安排中打开 → 安排开始 → 撤回到未安排
等待原因项目列表的待领取分组：依赖未满足、名额已满；agent-tools 项目：电脑离线
Agent 创建的任务项目列表 → 「整理 Web Push 订阅流程」，查看来源会话与修改记录

模拟与未包含

  • 「在 Pi Reach 中打开」「在 Remote Control 中打开」只弹出提示，不实际跳转。
  • 不包含：设置页、任务编辑页、依赖编辑、拖动排序、推送通知、深色与浅色手动切换（跟随系统）。
  • 用户和 Agent 写的任务内容在英文界面下原样显示，不翻译，与 Pi Reach 的规则一致。

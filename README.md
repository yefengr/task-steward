# Pi Steward — 任务管家

Pi Steward 是面向个人的跨电脑任务清单与执行协调系统：在自己的清单中安排工作，由项目所在 Mac 上的启动器自动领取任务并启动 Agent（Pi 或 Claude Code）执行，集中查看交付、接收通知并完成验收。

`pi-steward` 是当前项目目录名与工作名称，正式产品名称尚未确定。Steward 意为管家或受托管理事务的人，这里指替用户安排、跟踪和协调 Agent 任务的角色。

## 阅读重点

本系统是一个任务台账，加上每台 Mac 上自动领取任务的启动器。平台部署在私人服务器，以单 Docker 容器运行，负责清单、领取条件、交付记录和通知，不接模型，也不托管 Agent 进程。任务怎么完成交给项目 Agent 和项目已有规范，源码与工作现场保留在执行电脑。

启动器按本机空闲名额自动领取任务，在后台 tmux 会话中启动新的 Agent 会话（暂定）。名额等于本机运行中的 Agent 进程数，默认 1；Agent 等待用户回应时进程仍在运行并占用名额，进程退出即释放。Pi 经任务扩展、Claude Code 经通用技能回报进展、问题、决定与交付，Claude Code 经 ccx 启动并通过系统提示词获得任务背景。Agent 交付后结束进程，任务进入待验收；需要修改时用户发起返修，任务优先重新领取。进程退出而没有交付时任务进入已中断，由用户决定是否重新安排。

对话通过各 Agent 的远程入口进行：任务记录执行电脑、Agent 类型与会话标识，Pi 会话在 Pi Reach 打开，Claude Code 会话经 Remote Control 打开，精确会话深链作为后续增强。首版先接 Pi，任务在创建时指定 Agent。Agent 还可以在用户要求时代为查看、创建和修改任务，安排开始与验收仍由用户在平台操作。依赖默认等待前项验收通过，也可选择交付后继续；待验收超过上限时暂停领取普通任务，返修不受限制。
